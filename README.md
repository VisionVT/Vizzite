# Vizzite

**Vizzite** is a Bazzite-based Linux distribution designed with visually impaired gamers and computer users in mind.

Built on the foundation of Bazzite, Vizzite focuses on making gaming, everyday computing, and system navigation more accessible without sacrificing performance. It aims to provide a familiar, gaming-focused Linux experience with accessibility features thoughtfully integrated throughout the operating system.

### 👁️ Designed for Accessibility

Vizzite is built around the idea that visual accessibility should be part of the operating system from the start. It aims to provide features such as enhanced screen-reader support, high-contrast interfaces, customizable text and display settings, magnification tools, and accessibility-focused defaults.

### 🎮 Gaming First

Vizzite keeps the gaming features that make Bazzite popular, while adapting the experience for users who need additional accessibility support. Steam, gaming tools, controller support, and other gaming-focused features remain central to the experience.

### ⚙️ Familiar Linux, Made More Accessible

Vizzite is intended to feel like a complete desktop operating system rather than an accessibility add-on. The goal is to make common tasks such as installing applications, managing settings, browsing files, and launching games easier to navigate using keyboards, screen readers, magnification, and other assistive technologies.

### 🚀 Built for Everyone

Whether you're a gamer, developer, student, or everyday computer user, Vizzite aims to provide a powerful Linux desktop that puts accessibility at the forefront.

**Vizzite: Gaming without barriers.**
